The error you're seeing is because QGIS is installed on your Mac, and it's interfering with Python. When you type `python3`, it's using QGIS's Python instead of the system Python.

Here's how to fix it:

**Option 1: Use the system Python directly (RECOMMENDED)**
```bash
/usr/bin/python3 yourdad.py scan all 2>&1 | tee scan-output.txt
```

**Option 2: Check which Python you're using**
```bash
which python3
```

If it shows something like `/Applications/QGIS.app/...`, then use Option 1.

**Option 3: Use the menu script instead**
```bash
./yourdad
```

This should use the correct Python automatically.
