Get Your Mac's System Report Card

Comprehensive system analysis delivered in a clear, report card format. Understand your Mac's performance, storage, and memory usage with detailed insights and actionable recommendations.

🚀 QUICK START

Already have Python 3.9+ installed? Run these commands:

# Navigate to the tool
$ cd ~/Downloads/yourdad-for-livvy

# Check memory/CPU
$ python3 yourdad.py scan cpu

# Check storage
$ python3 yourdad.py scan storage

# Or run both
$ python3 yourdad.py scan quick
💡 Tip: Your browser will open automatically with a beautiful HTML report!

⚙️ SETUP GUIDE

First Time Setup:

  1. Check if Python is installed:
    $ python3 --version
    Need 3.9 or higher ✅
  2. Don't have Python? Download Python

    Install from python.org (~50 MB, no Xcode needed!)

  3. Unzip the tool: Double-click yourdad-for-livvy.zip
  4. Open Terminal: Cmd+Space → type "Terminal" → Enter
  5. Run a scan: See Quick Start commands above ⬆️
⚠️ Security Warning? First time only: Right-click → Open, or System Settings → Privacy & Security → "Open Anyway"

🆘 TROUBLESHOOTING

Common Issues:

❌ "command not found: python3"

→ Install Python from python.org

❌ "No such file or directory"

→ Make sure you're in the right folder: cd ~/Downloads/yourdad-for-livvy

⚠️ Security warning about "unidentified developer"

→ Right-click the file → Open (first time only)

→ Or: System Settings → Privacy & Security → Click "Open Anyway"

❌ Not enough space (16 GB for Xcode)

→ Don't install Xcode! Use Python from python.org instead (only 50 MB)

❌ "SRE module mismatch" or "AssertionError"

→ You have QGIS installed. Use the menu script: ./yourdad

→ Or use system Python: /usr/bin/python3 yourdad.py scan all

❓ Can't open .md files

→ You're reading the HTML docs now! This replaces the .md files.
