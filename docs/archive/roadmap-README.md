## Organization Rules

1. **Single Source of Truth:** `PRIORITIZED-ROADMAP.md` is the main roadmap
2. **Active vs. Reference:** Keep active planning docs here, move completed to `docs/archive/`
3. **Update After Sessions:** Update `PRIORITIZED-ROADMAP.md` after each chat session
4. **One Roadmap:** Don't create multiple roadmap files - use the prioritized one

---

## When to Archive

Move documents to `docs/archive/` when:
- Feature is complete and implemented
- Planning is superseded by newer documents
- Document is no longer actively referenced

**Example:** `text-ui-prd.md` could be archived since `TUI-DESIGN-DOCUMENT.md` supersedes it.
