# Review Workspace — Symlink Staging for Safe Deletion

**Version:** 0.2
**Feature Type:** Core workflow enhancement
**Priority:** High (makes action easy without risk)
**Effort:** 1-2 weeks

---

## Problem

Users find large files and duplicates via reports, but taking action is awkward:
- Clicking file:// links opens each file individually
- Navigating to deep paths in Finder is tedious
- Users want to review multiple items at once
- Scared to delete wrong thing (no easy undo visualization)

**User quote:** "I see the list of large files, but now what? I have to click 20+ links and dig through folders?"

---

## Solution

Create a **symlink review workspace** where users can inspect files safely in Finder before deleting originals.

### Core Concept
1. Tool generates `~/.dadware/review/` workspace
2. Symlinks to large files and duplicate groups organized by category
3. User opens workspace in Finder, reviews everything in one place
4. Instructions show how to delete **originals** (not symlinks)
5. Optional: Generate trash script user can review and run

## Implementation Details

### Workspace Structure

```
~/.dadware/review/
└── {timestamp}/
    ├── README.txt                 # Instructions
    ├── large-files/
    │   ├── 01_{size}_{name}       # Symlink, sorted by size
    │   ├── 02_{size}_{name}
    │   └── ...
    ├── duplicates/
    │   ├── group_{id}_{filename}/
    │   │   ├── KEEPER_{name}      # Suggested keeper
    │   │   ├── DELETE_{name}      # Candidates
    │   │   └── README.txt         # Group info
    │   └── ...
    └── manifest.json              # Metadata
```

### Symlink Naming Convention

**Large files:**
- Format: `{rank}_{size}_{original_name}`
- Example: `01_8.4GB_Final_Cut_Project.zip`
- Sorts naturally by size in Finder

**Duplicates:**
- Folder per group: `group_{id}_{filename}/`
- Prefix: `KEEPER_` or `DELETE_` based on recommendation
- Example: `KEEPER_movie.mp4`, `DELETE_movie(copy).mp4`

### README.txt (Top Level)

```
────────────────────────────────────────
 REVIEW WORKSPACE — Dad Ware
────────────────────────────────────────

This workspace contains SYMLINKS to files you might want to delete.

HOW TO USE:
1. Browse folders below (large-files, duplicates)
2. Right-click any symlink → "Show Original" to see the real file
3. Delete the ORIGINAL file (send to Trash)
4. Do NOT delete symlinks (does nothing)

WHY SYMLINKS?
- Safe: can't accidentally delete by deleting symlinks
- Convenient: review everything in one place
- Easy: right-click → Show Original → delete

ALTERNATIVE:
Run the generated trash script (review first!):
  ~/.dadware/scripts/trash_{timestamp}.sh

────────────────────────────────────────
Generated: November 9, 2025 14:23
Scan report: ~/.dadware/reports/storage_2025-11-09_14-23.html
────────────────────────────────────────
```

### README.txt (Duplicate Group)

```
────────────────────────────────────────
 DUPLICATE GROUP — movie.mp4
────────────────────────────────────────

File size: 100 MB
Duplicates found: 3 copies
Space if cleaned: 200 MB (keep 1, delete 2)

RECOMMENDATION:
✅ KEEP: ~/Movies/movie.mp4
   (newest file, most logical location)

❌ DELETE:
   • ~/Desktop/movie(copy).mp4
   • ~/Downloads/movie.mp4

HOW TO DELETE:
Right-click any "DELETE_" symlink → Show Original → Send to Trash

────────────────────────────────────────
```

## Technical Implementation

### Symlink Creation

```python
import os

def create_symlink(target_path, link_path):
    """Create symlink, handling errors gracefully"""
    try:
        os.symlink(target_path, link_path)
    except FileExistsError:
        # Skip if symlink already exists
        pass
    except OSError as e:
        print(f"Warning: Could not create symlink for {target_path}: {e}")
```

### Workspace Generator

```python
def create_review_workspace(scan_results, top_n=50):
    """Generate review workspace from scan results"""
    timestamp = datetime.now().strftime("%Y-%m-%d_%H-%M")
    workspace_dir = Path.home() / ".dadware" / "review" / timestamp

    # Create structure
    workspace_dir.mkdir(parents=True, exist_ok=True)
    large_files_dir = workspace_dir / "large-files"
    large_files_dir.mkdir(exist_ok=True)

    # Create symlinks for large files
    for rank, item in enumerate(scan_results['top_files'][:top_n], 1):
        size_human = format_size(item['size_bytes'])
        link_name = f"{rank:02d}_{size_human}_{item['name']}"
        link_path = large_files_dir / link_name
        create_symlink(item['path'], link_path)

    # Generate README
    write_readme(workspace_dir, scan_results, timestamp)

    return workspace_dir
```

### Trash Script Generator

```python
def generate_trash_script(workspace_dir):
    """Generate AppleScript-based trash script"""
    script_content = """#!/bin/bash
# Generated by Dad Ware - Review before running!
# This script moves files to Trash (recoverable)

"""

    # Find all DELETE_ symlinks
    dupes_dir = workspace_dir / "duplicates"
    for group_dir in dupes_dir.glob("group_*"):
        for symlink in group_dir.glob("DELETE_*"):
            target = os.readlink(symlink)
            # Use AppleScript to move to Trash (recoverable)
            script_content += f'osascript -e \'tell app "Finder" to move POSIX file "{target}" to trash\'\n'

    # Write script
    script_path = Path.home() / ".dadware" / "scripts" / f"trash_{timestamp}.sh"
    script_path.parent.mkdir(exist_ok=True)
    script_path.write_text(script_content)
    script_path.chmod(0o755)  # Make executable

    return script_path
```

## Safety Features

### Multiple Layers of Safety

1. **Symlinks only** - deleting symlink does nothing to original
2. **Clear naming** - `KEEPER_` vs `DELETE_` prefixes
3. **README everywhere** - instructions in every folder
4. **Trash, not delete** - AppleScript uses Trash (recoverable)
5. **Dry-run mode** - preview before executing
6. **Confirmation required** - trash script requires explicit `--execute` + confirmation

### What Could Go Wrong?

| Risk | Mitigation |
|------|------------|
| User deletes wrong original | Clear labeling, README in each group |
| User runs script without reviewing | Requires `--execute` flag + confirmation prompt |
| Symlinks break (files moved) | Workspace is point-in-time snapshot, expected to be stale |
| User expects symlinks to update | README explains this is a snapshot, not live |
